1. DESCRIPCIÓN GENERAL
================================================================================

Esta API permite la comunicación entre la plataforma docente y las aplicaciones
de juegos educativos externos (Caracterizar, Clasificar, Seriar, Rompecabezas).

Base URL: http://localhost:4000

La integración funciona en dos pasos:
  • La plataforma docente INICIA una sesión de juego y obtiene un token temporal.
  • La app de juego RECIBE ese token y, al finalizar la partida, ENVÍA los
    resultados de vuelta a la API.

3. AUTENTICACIÓN Y SEGURIDAD
================================================================================

La API usa DOS tipos de tokens JWT. Cada endpoint requiere uno específico:

  ┌─────────────────────┬─────────────────────────────────────────────────────┐
  │ Token               │ Descripción                                       │
  ├─────────────────────┼─────────────────────────────────────────────────────┤
  │ JWT Docente          │ Se obtiene al hacer login en la plataforma.        │
  │ (access_token)       │ Válido por 1 hora.                                 │
  │                     │ Usado SOLO para: POST /api/juegos/sesion           │
  ├─────────────────────┼─────────────────────────────────────────────────────┤
  │ Session Token       │ Se genera al iniciar una sesión de juego.          │
  │ (sessionToken)       │ Válido por 2 horas.                                │
  │                     │ Usado SOLO para: POST .../detalles                 │
  │                     │ Es específico para UNA sesión de juego.            │
  └─────────────────────┴─────────────────────────────────────────────────────┘

  Ambos tokens se envían en el header Authorization:
    Authorization: Bearer <TOKEN_AQUI>

================================================================================
4. ENDPOINT 1: INICIAR SESIÓN DE JUEGO
   (Lo usa la Plataforma Docente)
================================================================================

  URL:     POST http://localhost:4000/api/juegos/sesion
  Auth:    Bearer <JWT_DOCENTE>    (obtenido del login)

  BODY (JSON):
  {
    "metricaSesionId": "6a1f9325-af8e-4c5c-8eec-12446a2a45f0"
  }

  Donde:
    • metricaSesionId  →  UUID del registro existente en la tabla metricas_sesion.
                          Este registro debe haberse creado previamente en la BD.

  RESPUESTA EXITOSA (200):
  {
    "sessionToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6...",
    "metricaSesionId": "6a1f9325-af8e-4c5c-8eec-12446a2a45f0",
    "nombreEstudiante": "Juan",
    "apellidoEstudiante": "Pérez",
    "appCriterio": "Caracterizar",
    "tituloActividad": "Juego de Clasificación - Nivel 1",
    "descripcionActividad": "Clasifica los objetos por color y forma"
  }

  La plataforma debe pasar TODA esta información a la app de juego.
  La app de juego necesita al menos: sessionToken y metricaSesionId.

================================================================================
5. ENDPOINT 2: REGISTRAR RESULTADOS DEL JUEGO
   (Lo usa la App de Juego externa)
================================================================================

  URL:     POST http://localhost:4000/api/juegos/sesion/{metricaSesionId}/detalles
  Auth:    Bearer <SESSION_TOKEN>  (recibido de la plataforma docente)

  Ejemplo de URL real:
    POST http://localhost:4000/api/juegos/sesion/6a1f9325-af8e-4c5c-8eec-12446a2a45f0/detalles

  BODY (JSON):
  {
    "duracionSesion": "00:15:00",
    "intentosPorElemento": 4,
    "tasaAcierto": 75.5,
    "secuenciaDecisiones": {
      "pantalla1": "correcto",
      "pantalla2": "incorrecto",
      "pantalla3": "correcto"
    },
    "usoAyudas": 2,
    "nivelDificultad": 1,
    "abandono": false
  }

  RESPUESTA EXITOSA (201):
  {
    "id": "uuid-generado-automaticamente",
    "metrica_sesion_id": "6a1f9325-af8e-4c5c-8eec-12446a2a45f0",
    "duracion_sesion": "00:15:00",
    "intentos_por_elemento": 4,
    "tasa_acierto": 75.5,
    "secuencia_decisiones": { ... },
    "uso_ayudas": 2,
    "nivel_dificultad": 1,
    "abandono": false
  }

6. REFERENCIA DE CAMPOS
================================================================================

  CAMPOS DEL BODY — POST /api/juegos/sesion/{id}/detalles:

  ┌───────────────────────┬──────────┬────────┬──────────────────────────────────┐
  │ Campo                 │ Tipo     │ Requi. │ Descripción                      │
  ├───────────────────────┼──────────┼────────┼──────────────────────────────────┤
  │ duracionSesion        │ String   │ Sí     │ Duración del juego.              │
  │                       │          │        │ Formato: "HH:MM:SS" o texto      │
  │                       │          │        │ Ej: "00:15:00", "5 minutos"      │
  ├───────────────────────┼──────────┼────────┼──────────────────────────────────┤
  │ intentosPorElemento   │ Int      │ Sí     │ Número de intentos que realizó   │
  │                       │          │        │ el estudiante por cada elemento. │
  ├───────────────────────┼──────────┼────────┼──────────────────────────────────┤
  │ tasaAcierto           │ Float    │ Sí     │ Porcentaje de aciertos (0-100).  │
  │                       │          │        │ Ej: 75.5                         │
  ├───────────────────────┼──────────┼────────┼──────────────────────────────────┤
  │ secuenciaDecisiones   │ JSON     │ Sí     │ Objeto con las decisiones del    │
  │                       │          │        │ estudiante en cada pantalla.     │
  │                       │          │        │ Formato libre (ustedes definen). │
  ├───────────────────────┼──────────┼────────┼──────────────────────────────────┤
  │ usoAyudas             │ Int      │ No     │ Cantidad de veces que usó ayuda. │
  │                       │          │        │ Default: 0                       │
  ├───────────────────────┼──────────┼────────┼──────────────────────────────────┤
  │ nivelDificultad       │ Int      │ Sí     │ Nivel de dificultad completado.  │
  │                       │          │        │ Ej: 1, 2, 3...                   │
  ├───────────────────────┼──────────┼────────┼──────────────────────────────────┤
  │ abandono              │ Boolean  │ No     │ Si el estudiante abandonó el     │
  │                       │          │        │ juego antes de terminar.         │
  │                       │          │        │ Default: false                   │
  └───────────────────────┴──────────┴────────┴──────────────────────────────────┘

  VALORES VÁLIDOS PARA appCriterio (referencia):
    • Caracterizar
    • Clasificar
    • Seriar
    • Rompecabezas

================================================================================
7. CÓDIGOS DE ERROR COMUNES
================================================================================

  ┌──────┬─────────────────────────────────────────────────────────────────────┐
  │ 400  │ Bad Request — Datos inválidos en el body o UUID con formato malo.   │
  │ 401  │ Unauthorized — Token no proporcionado o expirado.                   │
  │ 403  │ Forbidden — Tipo de token incorrecto para el endpoint.              │
  │      │   • Usaste un sessionToken en el endpoint del docente.              │
  │      │   • Usaste un JWT docente en el endpoint del juego.                 │
  │ 404  │ Not Found — La sesión (metricaSesionId) no existe en la BD.         │
  └──────┴─────────────────────────────────────────────────────────────────────┘
