CONFIGURACIÓN GENERAL DE PRUEBAS
--------------------------------------------------------------------------------
- URL Base local: http://localhost:4000
- Todas las peticiones de escritura (POST/PUT) deben usar:
  * Headers: {"Content-Type": "application/json"}
- Los endpoints protegidos requieren identificar al usuario con:
  * Headers: {"x-user-id": "UUID_DEL_USUARIO"}

1. POST /api/auth/login
--------------------------------------------------------------------------------
Descripción: Autentica un usuario con email/cédula y contraseña.
- URL: http://localhost:4000/api/auth/login
- Headers:
  {
    "Content-Type": "application/json"
  }
- Request Body (JSON):
  {
    "cedulaOrEmail": "docente.utn@utn.edu.ec",
    "password_raw": "Admin123*"
  }
- Response (200 OK):
  {
    "user": {
      "id": "a0000000-0000-0000-0000-000000000001",
      "cedula": "1000000001",
      "email": "docente.utn@utn.edu.ec",
      "rol": "docente",
      "activo": true
    },
    "perfil": {
      "id": "d0000000-0000-0000-0000-000000000001",
      "nombre": "Jordan",
      "apellido": "Israel"
    }
  }
- JS Fetch:
  ```javascript
  fetch('http://localhost:4000/api/auth/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ cedulaOrEmail: 'docente.utn@utn.edu.ec', password_raw: 'Admin123*' })
  }).then(r => r.json()).then(console.log);
  ```
